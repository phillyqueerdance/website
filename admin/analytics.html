This browser is excluded by default when you open Admin. No visitor IDs, IP addresses, raw URLs or search text are stored. Dates use Philadelphia time; free usage limits reset at midnight UTC.

Free setup and limits

Use Workers Free and D1 Free. The collector also has a conservative daily write budget; quota failures stop collection. Keep the database on the free plan. Analytics uses the account's shared allowances.

Setup: create a D1 database, run migrations/0001_analytics.sql, bind it as QDP_ANALYTICS, and set QDP_ANALYTICS_FREE_PLAN to confirmed only after verifying Workers Free. Redeploy the site after changing bindings.

Custom date ranges cover up to 90 days at a time. Older daily counts remain available while database storage allows.
