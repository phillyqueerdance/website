Google Search

How people find QDP through Google Search. These figures are separate from visitor activity above.

Checking Google connection…

Connect the Google account that can view QDP in Search Console. QDP requests read-only Search Console access.

Set up the Google connection
  1. Open Google Cloud using the account with QDP's Search Console access. Create or select a project. No paid service is needed.
  2. Enable the Google Search Console API in that project.
  3. Configure Google Auth Platform. For a new app used only by its creator, choose Personal mode if available. External apps left in Testing need authorization again after seven days.
  4. Create an OAuth client of type Web application, named QDP Admin. Add this exact authorized redirect URI: https://queerdancephilly.com/admin/search-console-callback
  5. Enter the client ID and client secret below, save, then select Connect Google Search.

Credentials are encrypted on the server. They are never included in reports or sent to public-site visitors.

Collection

Checking collection…

This browser is excluded by default when you open Admin. No visitor IDs, IP addresses, raw URLs or search text are stored. Dates use Philadelphia time; free usage limits reset at midnight UTC.

Free setup and limits

Use Workers Free and D1 Free. The collector also has a conservative daily write budget; quota failures stop collection. Keep the database on the free plan. Analytics uses the account's shared allowances.

Setup: create a D1 database, run migrations/0001_analytics.sql, bind it as QDP_ANALYTICS, and set QDP_ANALYTICS_FREE_PLAN to confirmed only after verifying Workers Free. Redeploy the site after changing bindings.

Custom date ranges cover up to 90 days at a time. Older daily counts remain available while database storage allows.
